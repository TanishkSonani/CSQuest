# COA course plan

The course includes 35 topics, 105 designed microlevels and 420 challenges across six units. Each topic has three stages: learn the concept, manipulate or trace it, and complete an application checkpoint. Microlevels include a concept card, a complete worked example and four interactive challenges.

| Unit | Topics | Levels | Practice |
| --- | --- | ---: | --- |
| Computer foundations | 000-004 | 15 | Components, instruction fields, repeated addition, I/O, memory and boot |
| Memory and system bus | 005-010 | 18 | Addressability, byte placement, chip layouts, bus routing and bank access |
| Machine language | 011-019 | 27 | Registers, flags, opcodes, instruction formats, ALU and branches |
| Inside the CPU | 020-023 | 12 | Execution order, register transfers, effective addresses and memory references |
| Cache adventure | 024-031 | 24 | Fields, cache grids, replacement, dirty bits and access costs |
| Numbers in binary | 032-034 | 9 | Binary points, floating-point fields, normalization, range and precision |

## Learning experience

Start with one concept and an explicit model. Mix recall, classification, manipulation and application. Give immediate feedback and requeue incorrect answers. Track first-attempt accuracy separately from completion. Practice history supports later review while completed lessons remain replayable.

All numerical exercises state their widths, units and assumptions. Explanations distinguish an architectural model from physical implementation details. The [study guide](STUDY_GUIDE.md) collects teaching notes and worked practice.

The shared platform provides mobile layouts, keyboard access, reduced motion, both themes and saved account progress. Stable lesson IDs preserve progress during editorial updates. See the platform [lesson design standards](../../../docs/CONTENT_AUTHORING.md).
