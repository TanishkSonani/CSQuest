# Data Structures authoring

The published course covers all source IDs 0–100: linked lists, recursion, complexity, stacks, queues, expression processing, binary trees, BSTs, AVL rotations, heaps, hashing, probability and array layouts. It contains 303 levels, 1,212 exercises and 88 visual lab models across 16 units. The existing 219 levels retain their IDs and teaching data.

`topics.mjs`, `topics-extra.mjs` and `topics-final.mjs` contain original teaching, complete problem statements and answer banks. `build.mjs` requires completed, imported transcripts, selects timestamped source evidence, generates the browser content and sets `publishedLectureCount`. All 101 source topics have three playable levels each.

Run `node courses/ds/authoring/build.mjs`, `npm run validate`, `npm test`, `node --env-file=.env tests/ds-browser.cjs`, `node --env-file=.env tests/ds-advanced-browser.cjs` and `node --env-file=.env tests/ds-final-browser.cjs` after editing content. Run `node --env-file=.env tests/lesson-tools-browser.cjs` to audit diagrams across all subjects. Run `npm run db:import` to publish locally. The deployment pipeline imports the reviewed content into PostgreSQL without replacing learner accounts.

Transcription is complete. For future additions, transcripts do not automatically become ready lessons: review their topics, add original teaching and exercises, extend the contiguous curriculum/unit ranges in the builder, then rebuild and validate. This preserves existing lesson IDs and avoids empty or unreviewed challenges.

`packages/learning/ds-models.js`, `ds-advanced.js` and `ds-final.js` define deterministic walkthrough states. `ds-labs.js` renders them and provides touch/keyboard controls, replay and optional playback. Trees label depth; heaps label their zero-based array indices. Hash tables distinguish never-used slots from tombstones; heapsort distinguishes its active prefix from the final suffix. Array layouts show logical coordinates and physical memory order. Probability bars use a fixed zero-to-one scale, and stack timelines state entry/exit endpoints. Small trees fit phones and wider diagrams allow horizontal panning. Reduced-motion settings suppress animation. Graded exercises use choice, numeric, matching and ordering mechanisms; input diagrams show the starting state rather than the solution, and visual exploration does not change graded answers.

`topics-extra.mjs` contains the second batch's standalone teaching, explicit index/height conventions and exercise banks. `tests/ds-advanced.test.mjs` checks reconstruction, ancestral BST bounds, all four AVL cases, postfix operand direction and heap operations against independent expected results and randomized sort comparisons. Browser checks cover all lab kinds, unit boundaries, phone layouts, saved answers and course completion.

`topics-final.mjs` covers source IDs 73–100. `tests/ds-final.test.mjs` independently enumerates heap assignments, Catalan shapes, BST insertion permutations and uniform bucket allocations, checks heapsort against sorting, verifies tombstone/duplicate behavior, enumerates multidimensional storage order and simulates timing endpoints. Cost lessons distinguish model-based expected bounds from actual probe counts, and the random-node-height lesson explicitly avoids treating that experiment as a proof about arbitrary insertion keys. Collision lessons distinguish extra items from unordered colliding pairs.
