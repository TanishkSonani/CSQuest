# Lesson content review

Updated the 399 available Computer Organization and Digital Logic lessons to teach the subject concepts directly. Each lesson starts with a topic guide containing an everyday explanation, three key terms, and a worked example. Learners can open the same guide again during a puzzle. The lesson flow no longer displays transcript excerpts or assumes the learner has attended a recording.

Rewrote questions that referred to “the lecturer,” a transcript, a previous slide, or a model that had only been defined in another question. Technical questions now state the relevant bit width, input assumptions, signal polarity, counter rule, or circuit connection alongside the task. The chapter map and error history identify topics by name. Course catalog copy describes the prepared content as chapters and lessons rather than recordings.

Added 24 foundations for the COA curriculum and 38 topic guides for Digital Logic. Each guide is reused across related stages, so learners can revisit the necessary basics from a lesson or refresher. Existing answers, scoring and progress IDs remain stable.

The available lesson modules are saved in the local PostgreSQL database and the local app serves those updated modules. Courses whose content is still being prepared remain in their existing upcoming state; this update did not invent lessons for those subjects.

The new milestone chest uses a custom vector drawing with a green body, golden lid and jewel. It appears between lesson groups, reflects whether the group is complete and has no misleading click action or reward claim.
