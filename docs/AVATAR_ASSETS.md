# Character art and mascot

The selectable portrait atlas is saved at `apps/web/public/assets/avatars/characters-3d.png`. It was generated with the built-in imagegen tool using the imagegen skill. The selected output is a 1254×1254 RGBA PNG with a transparent background; CSS uses normalized positions, so the four-by-four layout is independent of pixel dimensions. No external image URLs are needed. The original generated file was copied into the repository, preserving its transparency.

`packages/learning/avatars.js` is the shared identifier and category catalog. The profile picker uses a keyboard-accessible radio group; categories filter the visible choices while preserving the selected avatar. Six original icon options remain valid for existing profiles. The Clash of Clans portraits are character fan art; CSQuest is independent.

## Generation prompt

```text
Use case: stylized-concept. Asset type: one production sprite atlas for selectable user profile avatars in a playful computer science learning app. Create ONE square 2048x2048 image containing an EXACT four-column by four-row grid of sixteen equally sized 512x512 portrait sprites, no gutters, no borders, no text or labels. Each tile contains a different centered head-and-upper-shoulders character bust with generous safe margins inside its tile; no sprite may cross its tile boundary. Consistent high quality rounded 3D game character rendering, soft clay-like materials, detailed sculpted hair and clothing, warm friendly faces, soft studio key light from upper left, subtle ambient occlusion, clean polished toy-like style, three-quarter front view, readable at tiny profile sizes. Truly transparent background around every character, no colored backgrounds or backdrop scenery, no cast shadow stretching out of the tile. Exact row-major character order: row 1: (1) young adult man, warm medium brown skin, short curly black hair, teal casual jacket; (2) young adult woman, warm brown skin, long dark wavy hair, lilac sweater; (3) friendly adult male nerd with round glasses, curly hair, orange hoodie; (4) friendly adult female explorer with auburn ponytail, tan safari hat, teal scarf. Row 2: (5) cheerful pirate captain with black tricorn hat, gold trim, small beard and red coat, no weapons; (6) friendly young male explorer with tan safari hat, brown skin and green jacket; (7) cute orange fox with large upright ears; (8) cute panda with black ears and soft fluffy face. Row 3: (9) curious golden owl with expressive eyes; (10) friendly teal baby dragon with little purple horns and small ears; (11) magical white unicorn with golden horn and lavender mane; (12) playful red-gold phoenix bird with sculpted feather crest. Row 4: recognizable Clash of Clans character avatar portraits rendered in the same polished 3D style: (13) Barbarian, bright blond hair, large yellow moustache, leather straps, friendly determined expression; (14) Archer, vivid pink hair, green hood, friendly confident face, no weapon; (15) Wizard, blue hood and robe, black goatee, friendly eyebrows; (16) Goblin, vivid green skin, pointed ears, red hair, mischievous friendly grin. All characters family-friendly, no weapons, no logos, no words. Tile centers must be exactly (256,256), (768,256), (1280,256), (1792,256), and equivalent row y centers 256,768,1280,1792. This atlas will be displayed using CSS background-position at 400% size, so equal tile geometry is essential.
```

## Native artwork and animation

Byte remains an original SVG character in `apps/web/public/icons.js`. The updated circuit body has shaded casing, a face display, antenna, shoes and articulated arms. `mascot.css` provides finite idle breathing and blinking, welcome waves, thinking tilts, encouragement and celebration hops. Lesson context selects the state; both reduced-motion controls disable animation. This retains editable vector joints instead of flattening the existing mascot into a bitmap.

The path chest is native shaded SVG in `apps/web/public/assets/chest-3d.svg`, with perspective, gold trim, wood grain and a lock. It replaces the previous flat outline.
