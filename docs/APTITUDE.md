# General Aptitude

The course includes 45 designed lessons and 180 challenges across five units: money, percentages and ratios; work, travel and numbers; spatial and analytical reasoning; absolute value, floor and ceiling; and grammar, vocabulary and reading.

Questions supply their own quantities, assumptions and relevant passages. Worked examples explain each calculation or logical conclusion. Visual labs include growth and price charts, percentage grids, ratio shares, work-rate bars, journey timelines, factor tiles, transformations, Venn diagrams, arrangements and number lines.

Diagrams support real input changes through sliders or typed values. Reset restores the example. Keyboard controls, phone layouts and light/dark themes share the platform's normal interaction patterns. Exploration does not change graded answers or award XP.

Course modules live under `courses/aptitude/content`. Use `npm run validate`, `npm test` and `node tests/aptitude-browser.cjs` for structural, model and browser checks. Publish content with `npm run db:import`; existing learner records remain intact.
