# Interactive teaching experience

All 11 subjects use designed lessons with concept guidance, model-backed predictions, worked examples and graded practice. The platform retains its shared theme, accessible controls, account system and progress rules.

## Learning controls

Predictions earn no XP and cost no hearts. An attempt opens exploration; incorrect predictions receive comparison hints. Glossary terms remain optional reference material. Saved rounds retain supported interaction state for recovery.

Multi-step examples support seeking, pause, restart, speed and synchronized captions. Static figures use meaningful parameter resets rather than pretend playback. Reduced motion uses manual steps. Detached lessons stop their timers.

Published lessons can be opened directly through the concept browser. Jumping does not award XP or complete skipped lessons. Next Lesson follows the selected lesson's order. Optional workshops and coding labs do not block normal progression.

## Model boundaries and verification

Educational models state their assumptions and limits. They are focused examples rather than full operating systems, database engines, network stacks or compilers. Some advanced lessons reuse a concept-family model alongside topic-specific notes and exercises.

Automated checks validate models, grading, persistence and content structure. Browser checks cover learning journeys, responsive layouts, both themes, reduced motion and cleanup. Subject-specific guides document additional limits. Responsive browser emulation does not replace physical-device, Safari or assistive-technology testing.
